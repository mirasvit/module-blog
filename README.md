# Mirasvit Blog for Magento 2 (archived free module, 1.x)

> **This repository is archived and no longer maintained.**
> It holds the old free `mirasvit/module-blog` package. Its last release was 1.0.43 in October 2020. It doesn't support current Magento and PHP versions and receives no security fixes, so we don't recommend installing it on a live store.
>
> The current Blog MX is a different, commercial extension: [Blog MX for Magento 2](https://mirasvit.com/magento-2-extensions/blog.html) ([user manual](https://mirasvit.com/manual/magento-2-blog-mx/)).

## What changed

This module started as a free Mirasvit blog for Magento 2 and was retired in 2020. Blog MX today is a separate package (`mirasvit/module-blog-mx`) that is actively developed and supported. It is not open source and is not distributed through this repository.

Blog MX adds, among other things, Page Builder posts, separate content per store view, a Content Checker that scores every post, WordPress import, built-in Hyvä support and compatibility with Magento 2.3 to 2.4.9. See the [product page](https://mirasvit.com/magento-2-extensions/blog.html) for the current feature list.

## Still running this module?

You can move to Blog MX and keep your posts, categories, and authors. [Contact Mirasvit support](https://mirasvit.com/contact.html) before you install it, and we will plan the upgrade with you.
